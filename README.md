# dannesk-indexer

[![Rust](https://img.shields.io/badge/Rust-2024_edition-000000?logo=rust&logoColor=white)](https://www.rust-lang.org)
[![ci](https://github.com/Dannesk/dannesk-indexer/actions/workflows/ci.yml/badge.svg)](https://github.com/Dannesk/dannesk-indexer/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/license-MIT-3B3F43)](LICENSE)

An async Bitcoin address index for a pruned Bitcoin Core node.

- Balances and unspent outputs for any mainnet address
- Address history within the node's prune window
- Mempool and block events for watched addresses
- Transaction broadcast
- Node and fee figures
